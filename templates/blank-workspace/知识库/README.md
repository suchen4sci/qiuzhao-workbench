# 个人工作区

这是当前桌面应用的最小空白模板，不包含演示人物、旧日期确认或历史投递。

- `profile.json`：个人事实的唯一运行数据源。优先在「设置 → 首次设置进度 / 个人资料与简历」维护。
- `06-网站适配/learned-fields.json`：用户确认后的字段对应关系，初始为空。
- 软件会在工作区自动建立 `.workbench/`，保存业务数据库、简历原件、修订和证据。不要手动改写数据库，也不要把整个个人工作区上传 GitHub。
- 首次引导可导入 PDF/DOCX、核对资料、设置默认 PDF 和发现偏好；邮箱与 AI 可跳过。
- 要迁移或保留完整数据，使用设置里的完整备份/恢复。单独复制 profile.json 不等于完整备份。

83 文件的旧空白模板保存在仓库 `docs/archive/blank-workspace-baseline/`；虚构示例仍在 `examples/demo-workspace/`，供参考和回归使用。
