# AI读取的配置与边界

普通快速填写可离线运行，不需要API Key。AI读取依赖本机可运行且已经登录的 Codex CLI，使用该账号的额度和模型设置。

请先在终端确认 `codex --version`、`codex login status` 能正常工作。程序也会尝试从 Windows Codex 桌面安装位置寻找CLI。CLI须支持 `exec --ignore-user-config --output-schema`；若版本不支持会显示错误，不应认为任务成功。

公开版默认关闭AI，开启前知悉：后台将以当前用户的完整本地权限执行，可读取工作区、访问网络、修改规则与资料；不是隔离沙盒。网页内容只作为数据，禁止自动最终投递和代签声明。不要在不信任的页面开启，也不要在演示身份上执行真实投递。

```powershell
$env:QIUZHAO_WORKSPACE = 'D:\我的求职资料'
$env:QIUZHAO_ENABLE_AI = '1'
npm start
```

打开招聘表单后，点击“AI读取”。流程：读取当前页面和知识库 → 修正规则 → 测试 → 热更新 → 调用实际快速填写 → 独立回读。最多3轮；每轮有超时，点“停止AI读取”可停止。当前页草稿和已访问保存页分别验证。网页上“填写完”不等于保存或提交。

日志放在 `秋招桌面助手/artifacts/ai-reader/`，可能含个人信息，禁止公开。遇到资料未知、附件未核验、声明或验证码，查看运行结果并由本人处理。

故障排查：检查CLI登录、代理、运行目录、模型权限和日志。程序读取系统代理用于CLI联网，但不导出登录凭据；本地浏览器连接只绑定127.0.0.1。远程调试端口不应转发给其他机器。
