## 还要开发

1. 完整发现链路：搜索线索 → 原文核验 → 资格/偏好解释 → 去重入库 → 摘要；增加语义候选与有限存量补查。
2. 扩大正式来源适配，企业/考公/事业单位/考研分别定义来源与流程；标签可选不等于来源已接入。
3. 可信单位 Logo、来源/缓存/失败回退、正式应用图标。
4. 外部通知渠道、持续部署，以及明确范围的软件关闭后提醒。
5. 自动更新及发行维护。
6. 本次前端视觉改版：先审阅生图，用户明确同意后再改代码。

## 还要真实验收

- 20–30 家来源、至少 100 条独立人工岗位基准、连续 7 天观察，报告召回/误过滤/延迟/成本。
- 正式网申多步骤、附件解析、会话变化、回执、人工接管及失败恢复。
- 真实邮箱、OCR/模型/搜索、系统密钥与 OS 通知、IME 与 Windows 真机。
- 生产托管、真实支付/回调/对账、持续云端与外部通知到达。
- macOS 签名/公证和跨平台安装/运行/升级。

百度单页解析已实现，但实时读取仍受本机 DNS/代理校验条件影响，没有把解析测试当真实网络验收。没有默认生产托管服务或支付环境。
