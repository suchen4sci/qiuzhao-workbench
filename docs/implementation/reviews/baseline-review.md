## 范围与结论

本轮只读取工作区代码、测试、计划和历史截图，唯一写入为本文。按委派约束未执行 Git 操作，因此**没有核对 HEAD、暂存区或准确的未提交文件集合**；下述为当前文件快照的实现审查，不能充当提交差异审查。未运行测试、真实站点、支付或邮箱验证，不能将已有测试源码解释为本轮测试通过。

现有产品有可复用的真实浏览器填表基础，但尚不是 Plan 所述完整系统。应保留稳定执行器，逐步建立结构化资料、机会、计划、申请、事件、资产与服务任务的数据边界。不能仅换首页样式就宣称 F1–F9 已交付。每个下面列出的子功能应单独委派审查 Agent，并记录实现证据、负面用例、残余风险与结论；本基线不能代替后续功能审查。

## 可复用基础与风险

| 范围 | 已有证据 | 差距或风险 |
|---|---|---|
| 桌面主进程与网页视图 | `desktop/src/main.cjs` 使用真实 WebContentsView、持久化招聘会话、规则扫描/填写/回读、busy 防并发 | 启动固定加载练习页；首次默认复制演示资料；需正式首次引导与演示隔离。人工键入自动暂停、附件上传及提交证据快照尚无完整链路 |
| 本地能力边界 | `main.cjs` 校验 IPC sender、主 frame 与 UI URL；`preload.cjs` 频道白名单；UI/guest 均 sandbox、contextIsolation、无 Node 集成 | 扩增 IPC 必须沿用校验并补输入验证；CDP 监听 loopback 仍属于强本地能力，不能把连接信息提交或暴露给网页 |
| BYOK 设置 | `ai-settings.cjs` 验证 HTTPS/loopback，禁 URL 凭据/查询参数，safeStorage 加密，弱 Linux 后端拒存，UI 不回传 Key | 这是用户自带 Key，不是托管服务、权益或支付。备份必须排除密钥；云端运营 Key 不能搬到客户端 |
| AI 字段映射 | `ai-mapping.cjs` 仅发送字段元数据，排除已有值/秘密字段/人工字段；catalog 校验、确认重扫与指纹校验、持久化映射备份 | 当前自动扫描所有候选，并非用户先选本次字段范围；只建立映射，非事实纠错建议。网页标签仍可能夹带个人文本，metadata-only 不等于已证明完全无个人信息；新增外发功能需明示范围 |
| 工作区初始化 | `workspace.cjs` 不覆盖已存在不完整目录、显式个人工作区用空模板、模板拒 symlink | 拷贝中断会留下不完整目录且后续拒绝恢复；需要临时目录/恢复路径。未提供工作区 schema 迁移、历史备份恢复及跨数据文件事务 |
| 现有本地岗位存储 | `dashboard/lib/store.mjs` 有写入队列、临时文件替换、版本冲突与岗位唯一校验 | 公司名+岗位名唯一无法区分招聘批次/地点；一行日期和下一步不足以表示多事件。不能直接兼作机会、计划、申请三种实体 |
| 桌面与看板接入 | `dashboard-import.cjs`、本地 server、岗位详情 UI 可作为迁移适配层 | 旧两入口及常驻资料栏需改为单一侧栏，不能长期并列两套主流程 |
| 测试与打包 | `tests/product-services.test.cjs` 已覆盖映射、Key、工作区、看板 API 安全等；package 有 Electron 打包与 smoke 脚本 | 新增模块需要业务不变量与跨模块闭环验证；旧测试存在不等于新计划通过，真实上传、邮箱、支付需独立环境验证 |

可确定的优先修复：默认演示数据隔离、实体拆分和迁移、个人事实与发现偏好隔离、真实浏览器人工接管、提交证据与状态分离。外部依赖（来源覆盖、邮箱 OAuth、搜索服务、托管模型、支付、云端持续运行）应明确接入状态；本地样例和 fake provider 不能冒充已上线服务。
