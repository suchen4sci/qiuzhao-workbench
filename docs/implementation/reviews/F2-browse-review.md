## UI 与安全核对范围

- 静态核对新列表、单位名、标签、筛选属性、清单预览与批量确认中的外部文字均经 `h()` 转义；服务只处理数据，未见执行导入文本的路径。
- 纯函数测试包含恶意 HTML 字符串，验证按普通标签处理、不执行代码；**这不等于已执行真实 DOM 的 XSS 攻击测试**。
- UI 保留隐藏选择时明确显示“包含筛选隐藏项”，批量确认再次列出全部选择，操作不会直接从筛选结果静默落库。
- 主 Agent 提供的实际 Electron 记录 `/tmp/qiuzhao-browse-smoke.log` 已阅读，其声明通过单位聚合、筛选、隐藏选择、批量日期/优先级/提醒、自动关注、清单预览与去重。此项为主 Agent 执行结果，不冒充本审查 Agent 独立操作。

## 小范围后续改进（非阻断）

批量确认目前对岗位只显示岗位标题。不同公司同名岗位或包含筛选隐藏项时，建议同时显示单位名称、城市和批次，便于用户核对具体选择。清单导入复用已有单位时故意保留原资料；如果要用新官网补全旧空值，应另提供可见选择，不能暗中覆盖。

本计划提醒开关限定日期/截止提醒；每日摘要为独立设置，仍可统计关闭单项提醒的待办，这与当前 UI 提示相符。
