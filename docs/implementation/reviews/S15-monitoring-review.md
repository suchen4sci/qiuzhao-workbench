# S15 云端公开页监控独立审查

审查日期：2026-10-03。范围：`hosted-service/monitoring.cjs`、server/http 接线、桌面 `services/hosted.cjs`/workbench 接线及 `cloudOpen`/`cloudAdd` UI。审查代理仅新增测试与报告，业务修复由主实现代理完成。

结论：**限定范围内复审通过，无未关闭的必修阻断项。** 独立服务端测试 10/10、桌面服务与动态 UI 函数测试 5/5，共 15/15 通过。本功能是用户明确选择公开页面的云端检查和通知箱，不等同于完整 S15 云服务、邮箱同步、截止提醒或外部消息推送上线；生产部署尚未配置。

## 已修复并复验

1. **P1：未确认也会先发送名称和链接。** 桌面 monitoring(add) 原先把 `confirmed:false` 连同 label/url 发到服务端，虽然服务器拒绝创建，外发已经发生。客户端现先验证显式确认再请求。测试覆盖 false 与缺失确认，网络调用均为零。
2. **P1：服务全局停用后用户无法撤销监控。** 原 update/remove/read 都依赖全局 enabled，UI 也隐藏操作，用户无法暂停或删除，服务重新启用后仍会继续。现全局关闭仍允许已登录用户暂停、删除和标为已读；新增/恢复仍要求启用。服务及实际 cloudOpen 函数测试通过。
3. **P2：重复开启或暂停再恢复绕过每日调度。** 原 update 总将 next_check 设为当前时间。同态操作现幂等，恢复保留下一次计划且不得早于 last_attempt+24h。重复开启与暂停恢复均未增加当天读取次数。
4. **P2：删除重建绕过限额。** 原频次仅存在于 monitor 行，删除再添加可立即重新抓取。现独立 `monitor_attempts` 保存账号、URL hash、最近尝试时间，删除监控不抹去限流；同 URL 24 小时一次，账号滚动 24 小时最多 20 次，48 小时后清理过期记录。测试覆盖同 URL 删除重建、轮换页面耗尽预算以及不同账号不互相占用预算。

| 范围 | 验证结果 |
| --- | --- |
| 账号隔离 | list 只返回所属账号的监控与通知，另一账号不能暂停/删除监控或读通知 |
| 授权与最小外发 | 客户端未确认零请求；确认后只发送 label、标准化 URL、confirmed，注入的个人资料、申请 ID、cookie 和密码未外发；不读取个人事实 |
| 链接与地址边界 | URL 拒绝远程 HTTP、本机/IP 字面量、凭据和非标准端口；地址分类拒绝私网、回环、链路本地及常见保留范围 |
| 新增上限 | 同账号同 URL 重复新增复用监控；21 个并存页面拒绝，另一个账号独立使用额度 |
| 调度 | 并发 tick 不重复抓取；暂停/恢复、删除重建和重启保留每日尝试预算；更换不同 URL 也不能超过账号滚动预算 |
| 并发停止 | reader 即使忽略 abort 并返回晚结果，暂停后的状态不回写，删除后的记录不重建、通知不产生 |
| 重启 | 未完检查变 interrupted，旧实例晚回复丢弃；当天不立即重复读取，24 小时预算恢复后可以成功并生成一次恢复通知 |
| 变化与失败 | 首次成功仅建基线；结构化岗位变化产生一次 changed，内容不变不重复；连续失败通知去重，恢复后产生 recovered；空/动态页面为 manual_required，未当作招聘关闭 |
| UI | 展示目标服务、长期每日检查授权、仅云端通知箱的能力边界；明确退出账号不暂停监控；全局关闭时保留暂停/删除；名称等外部文本转义 |
| 退出语义 | logout 只撤销会话和本地令牌，不暗中暂停或删除监控；与用户可见说明一致 |

静态复核：生产 reader 为既有 `readPublicPage`，每次 DNS 解析验证并将 HTTPS 连接固定到已验证 IPv4，跳转最多三次且限制同 origin；总读取约 15 秒、正文最多 1 MB、不接受压缩格式、无 Cookie 或浏览器登录态。监控只调用 `extractJobs` 解析当前页的结构化岗位，不执行网页脚本、不跟随岗位列表翻页、不调用模型。持久监控记录包含名称、完整 URL、检查状态/时间和结构化摘要 hash；通知文字为受控消息，不保存网页正文或个人简历。

## 验收边界与运营含义

- 首次检查可立即执行，之后正常成功/失败均至少隔 24 小时；限额按尝试计数，失败、取消或重启中断也消耗当次读取机会，因此中断后可能等待下一天。调度是每分钟触发、每批最多 20 个顺序读取，积压时可能更晚，未承诺精确到点或高并发 SLA。
- 删除监控会删除该监控及其通知，短期限流记录保留账号和 URL hash，最长约 48 小时后清理；这是防止重复重建绕过调用限制，未保留原完整链接在限流表中。
- 结构化内容变化仅提示回官网核对，不证明职位新增、关闭或企业开放状态。首次空页、动态渲染、登录页和抓取失败均需人工核验。
- “公开链接”校验无法判断任意 query/path 是否含个人令牌。UI 已明确不要提交带个人访问凭据的 URL；选择的完整链接会保存在服务端。没有上传邮箱内容、账号 Cookie 或个人资料。
- 本轮未进行真实网络目标 SSRF/DNS 重绑定演练、真实用户环境故障恢复、生产 TLS/容量测试、部署或外部推送。主实现代理另行报告的本地 HTTP 与 Electron smoke 应在主台账记录，不能视为本报告独立执行结果。
