## 需修复问题

1. **P1：个人资料编辑重绘丢失未保存输入。** `workbench.js:102–114,158–159`。`profileEditor()` 只读 state，切换分组、新增/删除记录没有先回收表单。复现：基本资料输入姓名 `UNSAVED`，切换教育再切回基本，姓名变为空（已在独立 Electron 临时工作区复现）。编辑一条教育经历再新增第二条也会触发相同重绘路径。应维护各组草稿，删除只作用目标记录；保存时保留其他组草稿。
2. **P1：偏好/个人资料跨导航静默丢草稿。** `workbench.js:24–31,120–126`。`show()` 每次刷新 snapshot，导航没有草稿保存或离开提示。已复现：新建偏好填 `PREF_UNSAVED`，再新增方案时输入仍保留；切今日→机会→编辑偏好后方案数回到 0。应在离开前保存本地草稿或提供明确保留/放弃机制。
3. **P2：计划热力图图例与颜色不一致。** `workbench.js:57` 与 `workbench.css` `.wb-legend`。计划安排模式日历为蓝灰色，图例固定为绿色；用户无法可靠解释颜色。应将图例绑定当前模式，显示分档与小圆点含义。
4. **P2：未知轮次被赋予一面色。** `workbench.js:15`。未知 round 使用 `interview-1`，文字虽为“面试”却与明确一面共享阶段颜色。应使用中性未知阶段色，仅已确认轮次进入渐深紫色序列。
5. **P2：全新用户添加面试陷入无单位可选状态。** `workbench.js:96,130,133`。面试空状态直接“添加面试安排”，但表单必填单位下拉为空且不能现场新建；用户必须退出到机会中先建单位。应在该表单增加新建单位或清晰的建立入口，成功后保留已填面试草稿。
6. **P2：UI 冒烟测试存在窗口选择竞态。** `tests/workbench-smoke.cjs:10–11` 使用 `app.firstWindow()`。本轮返回了 `fixtures/demo.html` guest 页面，导致等待首页标题 30 秒超时。独立诊断确认工作台 `src/ui/index.html` 实际正常加载。应按 URL 筛选工作台窗口，再执行断言，避免偶然通过的截图掩盖测试不稳定。
7. **P2：弹层缺少键盘焦点管理。** `app.js:27–31`。打开弹层不移焦点、无焦点约束，关闭不回到触发控件；只实现 Escape。键盘用户仍可能在被遮挡页面操作。应将弹层设为适当 dialog 语义并在打开/关闭时管理焦点。
