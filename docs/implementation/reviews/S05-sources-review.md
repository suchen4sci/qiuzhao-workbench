## 已发现并复核修复

1. **P2：手工机会和来源机会身份不一致，重复导入。** 原先来源使用独立 `opp-source-*` 标识，已有相同单位、岗位编号、批次、城市的手工机会仍会再建一条；来源标题变更也会改变 ID。最新实现先按稳定编号和业务维度查找已有机会，未覆盖手工标题/备注。两个专门用例及改描述后再次读取用例通过。
2. **P2：关闭中的来源一直显示读取中。** 原实现关闭只取消网络，source 留为 checking，运行记录未登记。最新实现在开始时登记 running，正常关闭写 interrupted，迟到的网络结果不能入库。关闭重开回归通过。

3. **P2 生命周期：进程异常退出的启动恢复。** 最新 createSources 初始化将上次遗留 checking/running 状态改为 interrupted，并保留最近成功证据。通过直接持久化遗留状态再重开工作区的回归，不需要真实杀进程。
4. **P3 日期格式：DateTime 尾部未验证。** 最新 date() 校验完整带时区 DateTime；无效尾部、无效小时、无效日历日期和无时区时间不会成为公告日期。合法偏移时间保留源日历日期，不因转换 UTC 跨天。

目前未保留未修复的 P1/P2 问题。安全网络全链路和真实来源覆盖实验仍受下述验证边界约束。

## 已验证的行为和安全边界

- URL 拒绝非 HTTPS、账号密码、IP 字面量、本地单标签域、`.local` 和非 443 端口；地址分类拒绝回环、私网、链路本地、CGNAT 和 IPv6。
- 代码逐跳解析 DNS，拒绝混入不允许地址的结果，通过自定义 lookup 固定已核验 IPv4；不共享连接池；最多三次同源重定向。没有网页登录态，也不执行网页脚本。
- 请求设 15 秒超时、1 MB 上限、允许内容类型和 identity 编码；JSON-LD 结构访问/候选数有限制。
- JSON-LD 图提取、完全相同候选去重、无效日期不猜、安全回退链接、描述去标签；空页面为 manual_required，不解释为招聘关闭。
- 明确勾选核验和填写单位/批次才入库；导入后开放状态仍为 unknown，保留原文 SHA256 和采集时间。
- 重新读取保留已采用草稿；不同正文的草稿再次确认不会覆盖已有机会的手工修改。
- 失败保留最近成功时间、原文、草稿和机会；确认中故障完整回滚单位和机会。
- 同一来源并发请求拒绝；关闭中止请求，迟到的结果不会写入。
- UI 输出使用转义，留存原文用 pre 显示，未插入执行原始 HTML；页面明确单页、分页未核验、无结构化结果需人工补充。核对弹窗提供岗位链接文本、日期、招聘类型、原文摘要、单位和批次，不宣称校招资格或开放状态已证实。
