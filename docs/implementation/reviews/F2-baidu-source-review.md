# F2 百度公开来源适配核对

日期：2026-10-04。当前聊天承接原聊天留下的 `source-adapters/baidu.cjs` 和 `sources.cjs` 初稿。本报告是本聊天的代码核对与测试记录，不声称已完成独立 Agent 审查或完整 D5a 验收。

## 实现范围

- 仅识别 `https://talent.baidu.com/jobs/list` 与 `jobs/detail/GRADUATE|INTERN/<UUID>` 的公开 HTML；其他页面沿用 JSON-LD。不调用未公开接口，不执行页面脚本，不自动翻页。
- 使用有界 JSON 解析读取 SSR 初始数据，允许观察到的裸 `undefined`；拒绝可执行表达式、重复初始数据赋值、损坏/过大正文、异常分页及身份不一致。
- 列表与详情严格分开，防止详情页内附带的无关列表污染候选；招聘类型、稳定编号、城市、正文和来源日期保留为待核对资料。
- 公开页发布日期/更新时间与有效标记独立保存，不自动推定开放时间、截止、开放状态或最终资格。详情页有效标记变化会改变草稿依据。
- 界面显示所读页、每页数量、网站报告总量以及未覆盖说明；确认导入仍保持 unknown。原文证据和人工更新保护沿用现有来源服务。

## 核对发现与修复

1. 初稿把整页 SHA256 放进岗位 proposal，导致无关 HTML 变化制造新草稿。已移除；整页 hash 仍由 evidence 保存，不参与岗位内容去重。
2. 逗号连接的多个城市会成为单标签，影响筛选。已分割、去重、排序，并保留现有数量上限。
3. 增加列表链接招聘类型一致性、重复 UUID、列表条数与总量一致性，以及同脚本多次初始赋值的拒绝路径。
4. 来源服务 legacy 证据回读共用适配选择；界面不再只给笼统的单页提示，明确展示实际 SSR 页数与总量。
5. 截图发现既有任务行的图标列将来源说明挤成窄列，改为独立的可换行来源布局；宽窗口与窄窗口实际 Electron 复验及截图核对通过。

## 验证

- 新增 5 项适配/事务测试；来源、更新、调度及既有审查测试合计 49/49 通过。覆盖执行语法不运行、身份冲突、日期不推断、无关页变化去重、失败保留旧岗位及计划/手改保护。
- 实际 Electron 隔离工作区测试通过：持久来源分页说明、来源日期展示、恶意标签转义、两次明确确认后导入、城市分离、开放时间仍未知、无自动申请或计划。
- 完整回归：桌面 461 项，460 通过、1 Windows 条件跳过；托管 36/36。随后仅增加解析拒绝及有效标记依据保护，相关 49 项再次通过。
- 原聊天留下的当日官网 HTML 快照：列表提取 10 条、网站报告 159 条；详情提取 1 条。两类均未自动设置开放/截止日期。快照保存在临时目录，未将完整官网内容提交仓库。
- 本聊天通过网页工具复核了[官方列表](https://talent.baidu.com/jobs/list?recruitType=GRADUATE)与[详情](https://talent.baidu.com/jobs/detail/GRADUATE/6f9c3a86-6557-409d-8fa7-e6f4c68d6765)的可读页面；这不替代应用网络读取验收。

## 未完成的边界

应用 `readPublicPage` 的实际联网测试未通过：沙箱中 DNS 无法解析；允许联网后 DNS 返回了被现有公网地址校验拒绝的地址。没有放宽地址检查或绕过来源访问保护。需在正常公网 DNS/受支持网络环境再次验证实际链路。

尚未完成自动分页、无人值守采集条款/频率验证、其他公司与招录/招生适配、100 岗位人工基准/7 天持续对比、资格语义提取及完整自动原文核验。因此本项仅交付单页来源适配，不代表百度岗位全集或已达到真实来源覆盖门槛。
