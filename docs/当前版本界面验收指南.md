# 当前版本试用与验收

更新：2026-10-05。对象为当前源码；旧安装包不包含所有最新功能，已移入本地归档。

```sh
cd /Users/zoey/Projects/qiuzhao-workbench
npm start
```

首次在新机器安装依赖执行 `npm run setup`。需要 Node.js 24 或更新版本。本机已有依赖；四个主入口是「今日、机会、投递、面试准备」，设置位于侧栏底部。

1. 设置 → 工作区管理：新建独立空白工作区。已有私人工作区无需重建，试用时不要覆盖。
2. 设置 → 首次设置进度：导入简历、核对事实、选择默认 PDF、设置偏好和摘要；可跳过邮箱、AI 或未准备好的步骤，退出后继续。
3. 设置 → 练习与帮助：用本地练习页验证普通填写。资料为空时不会凭空填满，先填写几项真实或明确测试资料。
4. 普通填写中尝试暂停/接管、手动修改、继续；继续会重扫并保留已有内容。第一次点击或按键仅用于暂停，不重放。
5. 机会 → 添加机会：建明确命名的测试岗位，加入计划；投递中查看安排、草稿和进度。填写完成不会自动登记已投递。
6. 添加测试测评/面试事件，查看今日、多场面试、月历计划与完成记录；完成一项不会清空其他任务。
7. 设置中导出完整备份；需要恢复时选择新的目录，不覆盖当前数据。

上述基础流程不需要 API Key。普通规则、人工维护和已有笔记不依赖托管额度。

AI/搜索需配置自己的服务或运营方部署的托管账号；邮箱需真实服务商的 IMAP 配置。没有默认生产服务。先验收基础流程，再单独检查真实模型、搜索、邮箱与系统通知；本地模拟测试不代替真实服务验收。
