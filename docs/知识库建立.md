# 从虚构示例建立自己的知识库

示例身份：林知远（虚构），2024年9月入读杭州电子科技大学计算机技术硕士，2026年9月为研三，预计2027年6月毕业；本科为浙江工业大学软件工程，高中为杭州市第十四中学。实习场景使用阿里云名称但任职完全虚构。项目覆盖 RAG、多智能体、工具调用、评测追踪和求职自动化。

1. 新建空白工作区，保留示例作为参考。不要直接替换原有私人知识库。
2. 编辑 `知识库/profile.json`。`values` 下每个栏目都是数组；一条经历一个对象，一项奖一个对象。实习不能放项目，学生工作不能当正式工作。
3. 基本信息、教育、家庭、薪资等只写已确认事实；未知值留空或不提供键。日期用 `YYYY-MM-DD`，只知道月份就用 `YYYY-MM`，不要编1日。
4. 描述保留完整正文。填表程序遇到字数限制会报告，不自动摘要事实。薪资明确税前/月薪/年薪单位。
5. 资料原件与确认依据放 `01-个人事实`、`02-经历与成果`、`04-附件索引`；附件状态和真实文件分别核验。
6. 完整虚构示例保留历史确认与教学组织范例；当前空白模板不再预置旧日期占位文件。业务记录、简历原件和修订由软件写入 `.workbench/`，字段映射保存在 `06-网站适配/learned-fields.json`。运行程序不从历史记录猜取个人答案。
7. 回到应用点击刷新资料，先跑本地练习页，再在真实页面核对字段。最终投递由本人操作。

示例目录按原知识库职责生成74份对应资料。原项目代码、编译缓存、登录快照和附件原件不复制；项目经历已换成AI Agent方向。所有标为虚构的成绩、奖项、导师和工作关系都不能当成真实材料。提供的是知识库模式，不是可冒用的简历。

`templates/blank-workspace/知识库` 提供最小可运行空白模板。原空白文件树已归档至 `docs/archive/blank-workspace-baseline/`；无需把这些旧占位材料复制到新工作区。运行字段与左侧显示名见[字段参考](字段参考.md)。
