## 使用技能

在仓库根目录运行 `npm run skills:install`。默认安装到当前用户的 `.codex/skills`；支持 CODEX_HOME。遇到同名技能保留现有文件，提示自行备份合并。

也可直接让代理读取仓库中的 `skills/qiuzhao-assistant/SKILL.md` 和 `skills/repair-resume/SKILL.md`。普通快速填写无需模型。AI读取需要另行安装并登录 Codex，设置 QIUZHAO_ENABLE_AI=1，详见 AI读取.md。

## 个人规则

`profile.json` 保留结构化 `values`；可按模块需要配置 `workflow`、`fieldTransforms`、`recordRepairs`、`attachmentCatalog` 等可选属性。它们应保存到私人工作区，不能把自己的答案提交回此仓库。模板不包含原用户的适配答案，遇到资料不足需自行补全并回读验证。

测试针对模拟表单和虚构资料，不代表已登录的所有真实招聘网站都已验证。网站改版后可能需要使用 repair-resume 继续适配。
