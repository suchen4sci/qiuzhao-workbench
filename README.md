# 招聘工作台

Electron 桌面产品：建立个人资料与简历，发现和关注机会，安排投递，填写网申，管理测评/面试与提醒，并按需使用 AI。

本仓库当前分支保存新版产品；原始 `main` 保留下载时的版本。当前源码和历史安装包的能力不同，体验新版请先运行源码。

## 本机启动

```sh
npm run setup  # 新环境安装依赖；本机已有依赖时可跳过
npm start
```

源码开发需要 Node.js 24 或更新版本。首次启动建立空白工作区；已有工作区保留，可在「设置 → 工作区管理」新建或导入。个人资料不随源码更新覆盖。

四个主入口：**今日、机会、投递、面试准备**。第一次使用进入「设置 → 首次设置进度」；试填表进入「设置 → 练习与帮助」。普通规则填写和人工管理不需要 API Key。验证码、声明和最终提交由本人核对完成。

## 目录说明

| 目录 | 现在的用途 |
|---|---|
| `desktop/` | 主产品源码、规则/控件/站点执行器、业务服务、UI、测试和启动脚本 |
| `hosted-service/` | 可选托管账号、AI 任务/额度/支付、公开页云端调度；需要独立配置与部署 |
| `dashboard/` | 旧 JSON 看板兼容组件，仍被桌面服务及测试使用 |
| `templates/blank-workspace/` | 当前最小空白工作区，初始化和打包必需 |
| `examples/demo-workspace/` | 虚构完整资料和旧证据组织范例，供测试/参考，不用于真实投递 |
| `skills/qiuzhao-assistant/` | 可选 DIY 求职工作流，保留上游许可；不是桌面应用的后台 |
| `tools/` | 工作区初始化与复制工具 |
| `docs/` | 当前使用说明、主计划、实施/审查证据、来源研究和设计 |
| `docs/archive/` | 旧规划、旧截图、旧视觉方向及原空白模板，不作为当前状态说明 |
| `.local-workspace/` | 本机私人数据，Git 忽略；保留，不上传 |
| `.local-archive/` | 本机旧构建与工具状态归档，Git 忽略；可按清单恢复 |
| `release/` | 下次打包重新生成的输出目录，Git 忽略；历史构建已移入本地归档 |

[完整目录盘点与整理记录](docs/目录盘点与整理-2026-10-05.md)解释每个模块的保留理由、历史材料与空间占用。[文档导航](docs/README.md)提供当前阅读入口。

## 能力与边界

- 本地工程已包含资料/文件版本、偏好与资格核对、机会反馈/摘要、计划/申请快照、规则填表/附件与人工接管、任务/月历、邮件待确认、本地提醒和面试笔记。
- AI 支持用户自带服务与可部署托管路径，包括选定字段映射/纠错、简历草稿、邮件草稿及岗位简报；调用范围和费用须明确确认。简历整理当前为自带服务路径。
- 搜索与公开页面只覆盖已实现来源。百度单页适配不等于岗位全集，未知开放状态仍须核验，不能承诺全网自动发现。
- 真实邮箱、OCR/模型/搜索质量、生产支付、持续云端部署与跨平台正式发行仍需独立验收。没有默认生产服务地址或 Key。
- 本地提醒依赖应用运行；云端公开页监控只有部署并启用后才持续工作，当前不含完整外部渠道推送。

详细范围以[主计划](docs/产品实施Plan-v1.md)为准，已验证状态以[实施台账](docs/implementation/实施与审查台账.md)为准。历史报告的“未实现”可能已被后续提交解决。

## 测试和打包

```sh
npm test           # 桌面与托管单元/集成测试
npm run test:smoke # 隔离 Electron 本地练习流程
npm run pack       # 当前平台 app 目录
npm run dist:mac   # macOS DMG
npm run dist:win   # Windows NSIS，真机验收仍需 Windows
```

安装包内置 Electron，用户无需另装 Node.js。当前无正式发行签名、公证或自动更新；不要用旧构建试验结果代表最新源码。构建会重新生成 `release/`，测试生成的日志/证据留在被忽略的本地目录。

## 数据与许可

`知识库/profile.json` 是工作区个人事实源；`.workbench/` 保存业务数据库、原件、修订及证据。优先用界面编辑与完整备份/恢复。空白模板已精简；完整虚构范例仍保留，不允许冒用。

私人简历、证件、邮件、Cookie、密钥、运行截图和本地数据库不应上传 GitHub；`.gitignore` 不会清除已提交的内容。模板、示例与历史资料属于公开仓库材料，仍须在公开发布前核对。
