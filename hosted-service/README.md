# 招聘工作台托管服务

当前提供可部署的单进程服务与桌面连接：邀请码注册、密码登录、短期会话、不可变范围报价、额度预留、完整结果结算、失败/取消释放、同请求幂等、Stripe 收银台及签名回调。尚未部署生产实例，也没有配置商户、真实模型、搜索供应商或收款价格；离线测试不能代表真实支付验收。

## 本机运行

需要 Node.js 24 或更新版本（内置 SQLite），无新增 npm 依赖。复制 `.env.example` 到本目录 `.env`，使用私密权限保存，设置运营方邀请码及模型配置。运行 `node --env-file=.env server.cjs`。桌面设置的“托管账号与额度”填写 `http://127.0.0.1:4318`，使用邀请码注册。生产地址须为 HTTPS 根地址。

`SERVICE_PRICES` 是 JSON 对象，可配置 `briefing`、`field-mapping`（桌面字段识别）、`field-correction`（桌面已填纠错）、`field-suggestions`（兼容事实匹配接口） 的正整数单次额度。没有默认价格；未定价的功能拒绝执行。模型配置是运营方的服务端凭据，不下发桌面。`CREDIT_PACKS` 是数组，每项为 `{ "id": "自定义标识", "units": 正整数额度, "amount": 最小货币单位整数, "currency": "usd" }`。支持两位小数的 usd/cny/eur/hkd/sgd；实际商户可用币种仍需在支付渠道验证。

没有支付配置时，可由运营方在服务主机执行 `node admin.cjs grant 用户邮箱 额度 唯一操作编号` 发放测试或补偿额度。重复同编号不重复入账。`node admin.cjs refund 用户邮箱 任务ID` 返还已结算任务的服务额度；这不是银行卡现金退款。不存在对外开放的充值或返还管理接口。

## 交付与数据

桌面会先告知发送范围再获取报价；获取报价不调用模型、不扣额度。用户再次确认后，以同一 requestId 发起任务，服务端在事务中预留额度。结果通过结构和原文依据检查后，保存结果并同时结算。失败、取消、进程恢复时无交付的任务释放预留。客户端网络失败用同一任务重试；已有结果可反复读取，不重复扣费。报价有效 10 分钟，同一报价不会创建第二份收费任务。返还后保留已交付结果。

`briefing` 当前读取用户提供的 1–5 个公开页面，未集成全网搜索供应商。事实必须有逐字来源，个人经历默认不发送且字段白名单过滤；推断明确标待核实。桌面 `field-mapping` 仅发送选定字段的名称、栏目、标题和控件类型，不发送事实值、选择器或整页；服务端使用通用字段目录生成建议。没有置信度达到门槛且合法的映射时释放额度。桌面重扫确认原申请与字段未变化，用户逐项保存对应关系后再主动填写。任务历史可在 AI 设置中刷新、取消或沿用同一任务重试；关闭窗口不取消远程任务。兼容 `field-suggestions` 接口支持调用方提供的事实匹配，桌面未使用该接口。自带 Key 模式与托管服务账本分开。

SQLite 目录包含账号、会话哈希、任务结果、额度账本和支付订单，应限制为运营方读写并做加密磁盘备份。服务使用单进程锁；请只部署一个实例，不共享到多个副本。重启会中断旧任务并释放预留，不在后台悄悄重调模型。

## 支付与上线边界

设置 Stripe 测试密钥、Webhook secret、额度包、HTTPS 返回地址后，开放测试收银台。Webhook 路径为 `/webhooks/stripe`，以原始请求字节验证签名及 5 分钟时间窗，核对 session ID、订单、金额、币种和已支付状态。只看到返回页面不入账；重复回调只入账一次。订单创建用渠道幂等键，超时应重试相同订单。

真实模式必须同时设置 `PAYMENTS_LIVE=true`、`LIVE_LAUNCH_ACCEPTED=true`，使用 live 密钥及完整模型配置。这个开关只是运营方声明，不是程序替你完成了真实验收。实际开通前仍需确认商户所在地/收款资格、有效结果成本、支付回调、退款支持流程、服务容量和隐私告知；此仓库未作这些生产验收。

收到现金退款或争议回调后，会冻结相应账号继续使用额度，并在 `payment_alerts` 记录人工核对任务；未知 intent 只记录，不冻结其他用户。乱序回调在对应订单入账时关联并冻结。运行中任务若账号冻结，不交付或扣额度，释放预留。当前没有自动现金退款、扣回和解冻管理界面；运营方必须先在 Stripe 核对，再按审计流程处理数据库，不能忽略未解决告警。

公开部署需要 HTTPS 反向代理、进程守护、私密环境变量、备份和告警。当前限速使用 socket IP，不信任 X-Forwarded-For；经同一个反向代理的客户端共享每分钟 120 请求和 10 登录尝试上限，不适合直接扩大公网容量。没有内置邮件验证/找回密码，当前限定邀请码试用。网页跨域请求不开放，原生客户端用 Bearer token；退出时尝试撤销服务端会话，本机令牌由系统钥匙串删除。

参考：[Stripe Checkout Session](https://docs.stripe.com/api/checkout/sessions/create)、[Webhook 签名](https://docs.stripe.com/webhooks/signature)。

## 可选云端公开页监控

默认关闭。运营方设置 `CLOUD_MONITORING_ENABLED=true` 后，已登录用户可从桌面「设置 → 云端公开页监控」明确上传单位/页面名称与公开 HTTPS 链接。服务每分钟调度到期项，每个链接至少间隔 24 小时检查；每个账号最多保存 20 页，滑动 24 小时最多启动 20 页读取。删除后重建、暂停再恢复不清空短期检查预算。URL 查询参数保留，因此只能填写公开链接，不应填带个人凭据的 URL。

首轮建立结构化岗位基线；后续结构化内容变化、读取失败及恢复写入账号隔离的通知箱。没有结构化岗位仅标「需人工核验」，保留上次哈希与成功记录，不标关闭。无登录浏览器、无限翻页或自动确认开放状态。用户退出桌面账号不会暂停已授权的监控，需先暂停/删除；运营方暂时关闭功能时，用户仍可暂停、删除及标记已读。通知最多保留每账号 100 条；删除监控同时删除其通知，URL 哈希/尝试时间最多额外保留 48 小时用于频率限制，不保留其名称或明文 URL。

本阶段渠道仅为云端通知箱，不含外部即时推送、邮箱同步、截止事件提醒；重新打开应用并刷新可读取消息。持续运行仍需部署、进程监管、TLS、数据库备份与出站联网。没有配置默认生产服务，不把本机调度测试视为已部署。服务中断后的到期检查会补做；已启动但中断的请求仍计入 24 小时限额，以避免重启放大调用。`lastTick` 表示调度最近运行时间，不能代替外部存活监控。

本机验证：`node --test tests/*.test.cjs`；根目录运行 `node desktop/tests/cloud-smoke.cjs` 验证真实 Electron UI + 本机 HTTP 服务（隔离虚构工作区与测试密钥适配）。

`field-correction` 独立配置正整数额度价，未定价不开放。桌面只发送所选字段元数据与本机存在可用且不同资料值的字段标识列表 `allowedMappings`，不发送网页现值、事实值、选择器、申请 URL 或资料 hash。服务仅接受高置信度、属于选定字段且在该字段允许范围内的映射；至少一项可用建议才结算。无建议或越界结果视为失败并释放预留。实际值选择、现值冲突验证和网页采用均在桌面本机进行，不作为网站保存或提交成功的证明。报价会明确这一交付定义；此服务的价格与普通字段映射分别配置。


`mail-parse` 是独立定价的邮件片段解析服务，默认不定价、不开放。请求范围仅为用户明确选择的连续原文 `text`（最多 20000 字）和用于本机/服务端独立日期校验的固定 UTC 偏移 `offset`。模型输入仅有片段与字段字典，不包含邮箱凭据、发件头、附件、其他邮件或用户资料；用户选择的片段自身可能含个人信息。

只有至少一项通过原文引用、字段结构校验且可供逐项采用的字段才结算。空结果、编造引用/值、仅有无法独立确认的日期等不可采用字段、异常或未交付取消均释放预留。类型/动作语义仍由用户核对，交付不等于已经创建事件。报价明示成功条件，采用与事件确认在桌面另行完成。

桌面报价和启动前验证邮箱待确认版本与来源片段；账号或服务切换不能访问另一账号未采用的交付副本。报价可本地取消，未确定远端接收时按同一请求 ID 重试；重启只读取历史，不自动创建新付费任务。生产仍需实际模型、HTTPS、价格成本评估、账号与支付配置；本机测试额度不证明生产支付已开通。
