# 企业知识库 RAG Agent（虚构项目）

【完全虚构的演示资料】以下人物、在校/任职关系、成绩、获奖和日期由程序示例编造；真实机构名称仅作场景，不能用于真实投递。

角色：项目负责人

日期：2025-03-01 至 2025-12-31

背景与目标：为模拟企业文档提供可追溯的问答服务，降低无来源回答的比例。
技术实现：使用 Python 与 FastAPI 构建检索服务，基于 PostgreSQL/pgvector 存储向量，结合关键词检索、向量召回及重排。通过 LangGraph 串联问题改写、检索、证据检查、回答生成和人工复核。为每次检索保留文档版本与引用位置。
测试成果：建立覆盖权限隔离、空检索、冲突证据和长文档的本地评测集，记录准确性、延迟与调用成本。本项目为虚构演示，不代表真实成果。
