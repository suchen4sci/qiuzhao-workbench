# 跨站批量准备与故障处理

在多网站选岗、附件上传、跨页保存及快速填写复现失败时读取。以下经验来自真实操作，通用原则与平台特例分开；现场实现改变时重新核验。

## 申请准备边界和顺序

1. 从实时工作台获取公司分组及所有标签，排除已投递、测评或面试中的单位，不凭卡片“待登录”判定真实会话。通过 src/active-page.cjs 和目标标签 ID 定位操作页；子标签仍属于原公司。
2. 自主找到校招入口并读取公告与岗位。核验届别、地点、学历、专业和截止时间。按用户当前优先级选择北京芯片设计/验证、FPGA、硬件、嵌入式，其次匹配技术岗位、售前及销售。销售只用授权的国央企销售版附件和对应经历，不能混用非国央企销售经历。
3. 查询平台/公司名额、已经占用的名额及共享限制；匿名计数、缓存“0申请”不能证明真实占用为零。未知标为未知，不通过试投查名额，不为凑名额选择不匹配岗位。
4. 进入具体申请表单后先上传正确授权简历，再修补全部栏目，保存/下一步，独立复核保存后的正文与附件。上传解析常改错专业、日期和归属，必须重新纠正。若平台要求先完善公共简历才能打开附件框，记录这个已核实的系统限制，先保存公共简历，再上传，随后重做正文及附件复核。
5. 用户只授权准备时，停在最终投递前。不能仅根据按钮名称判定动作；“立即投递”可能是表单入口，也可能立即产生申请。查看可读事件处理及实际路由/接口，先查明行为再点击。华电完整性检查后弹出的确认动作、华能材料弹窗的确定动作均可能提交，不能当作下一步。
6. 不保证所有站都能一次点击完成。独立保存草稿、只在当前预览保留、提交后才能准备第二岗、追加验证码等限制分别记录。真实完成状态只用待用户确认投递、草稿未齐、需登录、缺资料、技术阻断、岗位排除；未提交不得标已投递。

## 已发现原因与修复验收

| 症状/原因 | 处理方法 | 验收证据 |
|---|---|---|
| 头像/姓名显示已登录，但简历或申请入口跳回验证码页：缓存身份不等于有效会话 | 在具体入口读取真实认证结果；子标签异常同时检查同源会话继承及工作台会话分区，区分认证失效与应用丢会话。不能伪造登录或重复注册 | 受保护的简历入口实际可读；否则保存岗位和入口并标需登录 |
| 修改磁盘代码但快速填写仍旧：运行引擎未更新 | 核对当前任务占用，按现有脚本热更新运行引擎，不重启应用丢标签 | 真正 run('fill') 的报告和网页回读反映新规则 |
| 快速填写只填一两项：摘要卡未展开、iframe/弹窗未读或跨页没有保存 | 识别编辑入口，逐记录打开、填写、保存，等持久记录出现再添加下一条；每栏目完成后重新扫描 | 所有已确认应填字段及记录数量核对，不只统计当前空框 |
| 同校本硕专业混写、解析专业带附加标记或括号截断 | 按学校、学历、日期和专业身份定位；只在同一已识别记录内恢复知识库正式名称，保留原有精确匹配分支 | 两条教育记录各自字段及日期正确，二次运行没有重复记录 |
| 实习填成党支部/学生组织，或者正式工作被塞入实习 | 先识别是否存在独立正式工作、实习、校园经历栏目；有独立实习时仅在对应编辑器写实习，不把学生工作当就业 | 分别测试独立栏目与合并“工作/实习”旧结构；不凭字段“职务”孤立匹配 |
| 校园记录成员/队员、职务前缀别名导致重复 | 规范明确等价的身份名称，复用旧记录；队长与成员不是同一身份。校内学生干部栏只放符合该栏含义的记录 | 重跑两次数量不增加，未知记录和相邻栏目不变 |
| 雅思与六级次序不同导致分数错配 | 以考试身份定位，不按第几条记录分配；考试种类、语言、掌握程度分别匹配 | 调换考试记录顺序的测试仍正确 |
| 下拉框文本看似填入但未选中 | 区分原生 select、搜索字典、自定义选项；搜索后点击真实选项并核查选中状态 | 保存重开仍有选中值，输入文字本身不算成功 |
| 日期、单选、地区组件识别失败 | 支持 dl/dt/dd、就近标签、只读日期选择器、行内是/否和带说明选项；打开菜单前滚到稳定位置，失败后重读结构 | 日期按允许精度保存；必需区县未缺失；不去掉只读属性强写 |
| 平台文本过滤小数点、连字符、特定英文片段，成绩或技术描述被删改 | 回读实际值；在明确字段/站点作用域内使用等义中文或全角表达。考试数值框能接受小数时保留真实小数；不得把文本框过滤经验应用到所有分数字段 | 保存后的语义、单位和真实成绩不变；覆盖正常旧网站的负例测试 |
| 整数考试成绩框拒绝雅思小数 | 保存字段能力规则并联动考试名称和分数，采用用户确认的真实备用考试。若用户授权某站整数显示，作为站点显示政策单独记录，知识库真实成绩不改变，附件与说明仍保留实际成绩 | 实际快速填写重跑后不会恢复不合法小数或混搭考试 |
| ASP 表单下一页沿用上一页相同 input ID，等待旧 ID 消失挂住 | 用栏目/字段 cname、页面结构和保存响应判定变化，不仅等待复用 ID 隐藏 | 保存响应成功且新栏目明确，原栏目再次打开值保留 |
| 等待整站快速填写导致工具超时、连接状态丢失 | 在壳页面启动真实入口的异步任务，保留任务句柄并读取忙碌状态和结果；运行中不切换标签或启动第二个任务 | 任务结束后读取报告及真实值；仅“启动”不是完成 |
| 附件显示文件名或解析内容，但附件已丢失/没上传 | 核查成功响应、附件记录、实际下载及当前申请关联；保存后重开/预览再次核验。能下载时比对源文件哈希 | 文件真实存在且关联当前草稿；解析文字、100%完整度或本地路径不足以证明上传 |
| 简历超过网站大小限制 | 优先用户授权原件；确实超限时使用经文字、页数、版式与照片核对的同内容压缩副本，保持清楚的来源索引。上传后恢复解析误改字段 | 上传结果成功，下载哈希对应被上传版本，同内容验证记录保留 |
| 教育证明要求 ZIP 或图片 | 只打包该学历的真实授权证明，按真实材料类型上传；遵循用户图片优先偏好及网站接受类型 | 保存后附件记录仍存在；不得用大学材料冒充高中证明 |
| 必填本人签名、父母政治面貌、证明人联系方式等没有确认 | 记录缺资料，不用本人电话冒充证明人，不制造签名或法律事实。继续处理其他公司 | 已知栏目保存，缺项明确，不标可最终投递 |

## 沉淀到哪里

- 私人事实：现有私人知识库，以最新确认及授权附件为准。身份、家庭、联系方式、学校成绩和带签名网址不复制到技能或公开测试。
- 可复现技术修复：实际引擎的字段映射、控件执行、记录身份与流程模块。能力通用则增加结构分支；确为网站特例则限定 origin/path、字段和必要记录身份，保留旧规则。
- 用户偏好：从私人配置读取，例如技能掌握程度统一精通、调剂接受、优先的考试。不能硬编码他人的事实进通用技能。
- 每条学习记录含症状、根因、适用范围、代码/规则位置、针对性测试、旧回归、真实入口重跑结果、保存复核证据以及尚未解决部分。观察到问题但未完成修复的条目标待处理，不宣称已学会。

## 双重复核与回归

第一遍按知识库核对本人、教育/实习/项目归属及日期、语言、技能、岗位城市和简历版本。第二遍在保存后重开栏目/预览，读取实际持久值、记录数、校验结果、跨页内容及附件关联。每个岗位单独核验继承附件，不把公共简历附件自动视作每个申请都有。

先运行能暴露原故障的结构测试，更新实时引擎，再调用真实快速填写并逐字段回读，重跑检查幂等性。共享模块运行已有完整回归，不弱化验证器、删除断言或通过绕过正常控件报通过。无法登录旧站时明确只有隔离测试通过，未做旧站现场验证。

实际存在未解决问题时继续有证据的诊断；同一路径反复失败且无新证据时记录原因，转到其他站。整批报告逐公司、逐岗位列允许名额/实际占用、匹配依据、持久草稿、附件证据、最终按钮入口及待人工事项；不能只报告几家而隐藏剩余单位。


## 中国移动本轮补漏补充

- 高中独立校验分支：先选择学历，再读实际显隐与保存校验。该站高中只要求学校、起止日期及主学习经历；不能因大学模板显示证明星号而报告高中缺证明。已经实测无高中证明也能保存。
- 校内职务职责成就有50字服务器/前端限制，基于已确认事实生成短摘要并回读；任职日期只确认到月份、控件只接受完整日期且日期可选时，将月份放到描述，日期留空，不补造1日。
- 证明人联系方式虽标成泛称，实际控件只允许11位数字。微信号存入私人联系方式及合适说明字段，手机号未知须等待确认，不能去掉过滤器或把字母删掉后当电话保存。
- “已登录”的页面初始化可能先显示空壳。等待真实记录加载后再判断空缺，避免重复添加；保存后等待编辑器关闭及实际记录出现再处理下一条。

- 附件同名仍需核验服务端实际内容：中国移动本轮直接 PDF 上传后下载件被转换，页面尺寸和照片表现改变。网站允许 ZIP 时，可将已核对的压缩 PDF 包装为 ZIP，保存后用当前登录页面的下载入口获取，比较完整文件 SHA-256；不能以“上传成功”或文件名代替内容核验。此策略仅用于已观察到支持 ZIP 的上传控件。
- 家庭定义列表要等待编辑表单真正加载，再运行快速填写；生日别名“出生日期”按家庭记录范围匹配，不能套用申请人生日。

### 大易 dy-form 简历表单
- 字段显示名称来自 msg 属性或 dy-form-special 的隐藏字段 msg，不能用内部数字编号做字段名；按 edit-resume-div 标题和 subGroup 记录边界区分同名字段、本硕与家庭成员。
- input[choose-date] 使用 Bootstrap datetimepicker，按可见年份/月/日模式点击；只有月份事实而控件需要日时不得补造。
- 自定义奖励名称输入框依赖失焦提交到隐藏值，fill 后必须 Tab，核验隐藏提交值和重开预览中的名称；只看输入框文字会漏掉未保存的奖项。
- 简历解析可能将科研项目归为实习。备份后按真实资料迁移到项目栏，不能给项目虚构公司和证明人。
- 本轮电信证明人联系方式为自由文本，接受微信；不能沿用移动的纯数字限制。附件在重开后通过真实下载入口核验字节哈希。
# 智联 SCRD 逐栏与附件保存（2026-10-11 实测）

- `resume2` 链接不一定包含 `cid`，也可能通过 `projectId` 定义企业模板。旧分支仅判断 `cid` 会退回当前页通用填写，导致其他栏目未处理。不得直接将某公司的字段计划扩展至全智联；按已验证的项目标识、栏目结构和私人规则进入独立分支，保留旧分支。
- `src/zhaopin-verified.cjs` 与私人 `知识库/06-网站适配/智联逐栏已核验.json` 保存已实测记录身份及字段。模板属于已核验快照，个人资料变化后必须重新核对、更新，不能当作永久事实来源。未知模板继续正常扫描，不套用旧模板。
- 先匹配记录身份，再逐字段比较、编辑、保存和回读；教育同校不能只用学校匹配，至少增加学历。日期区间向未来移动时，若新开始时间超过旧结束时间，先改结束再改开始；避免被禁用日期阻断。
- Element UI 收起动画期间仍可有两个 `:visible` 日期弹层。排除 `el-zoom-in-top-leave-active` / `el-zoom-in-bottom-leave-active`，再定位唯一活动面板，不取第一个。
- “有奖学金”“是学生干部”等选项会动态展开字段，必须再扫描并保存。英语等级限定 CET/TEM、英语证书包含 IELTS 时分别填入对应考试及成绩，不能把雅思成绩配给六级。
- 附件只显示新文件名不代表保存。实测查看态直接上传后刷新恢复旧文件；应先点附件栏“编辑”，上传结束后点“保存”，再刷新核对服务器附件记录和文件名。文件超限可压缩授权副本，但必须核对文本与渲染；部分 PDF 重写图片 API 会破坏嵌入字体，出现文字消失，即使文件变小也不能上传。
- 实测验收：备份后清空一个可恢复的项目职责字段，由实际 `run('fill')` 恢复并保存；第二次重跑不新增重复记录；刷新回读栏目和附件。隔离测试 `tests/zhaopin-verified.test.cjs` 覆盖模板隔离、日期退场面板及重复运行；共享控件的旧回归仍需运行。不能将此验收宣称为所有旧网站现场验证。

### 中国通号 Phoenix 解析重复（2026-10-11）
顶端简历解析会将大学项目额外生成为实习记录；附件存在不表示正文正确。先按项目名称、起止月和完整描述核对独立项目栏目，再把已确认误放记录的完整指纹追加至私人解析纠错规则，限定精确来源和路径。现有 repairPhoenixRecords 可在真实快速填写中清理副本，overwrite 策略恢复原始职务/正文；第二次运行必须保持记录数量稳定。网站预览按钮对外部推荐身份可能自动提交，必须核实实际处理函数及 isExternal 配置；本次普通身份进入预览后另有确认投递，停在此处。已通过保存刷新和预览核验，不以快速填写待核验计数代替实际正确性检查。

### 2026-10-12 多站补齐复核
- 北森项目栏目可只有“项目描述/项目中职责/项目成果”，没有“项目名称”。不能因此把科研项目回填到“在校实践”。`src/add-projects.cjs` 增加该结构分支，以描述首行“项目：名称”保留记录身份；`src/engine.cjs` 识别该身份，任何独立项目栏目存在时都不将科研项目复制到在校实践。隔离用例验证两次执行不重复、旧有名称字段分支不变。
- 简历解析会清空学院/学位等下拉选项、混合校内职务、把项目新增成实习。先备份，再按完整记录指纹清理误分类；真实经历按身份恢复，不能仅按顺序覆盖。站点专用修复写入私人知识库的解析纠错规则及逐字段已核验规则。
- SD/Moka 页面在滚动中点击字段标题可能超时；标题仅用于关闭旧菜单，失败后 Escape 关闭，再点击实际控件。地区需解析完整省市区层级，直辖市去除重复市级，叶子选中已自动关闭时不要继续等待确认按钮。
- Phoenix 的“至今”必须核验组件的勾选态与实际记录值；原生 input.checked 变化不一定更新组件。通过可见“至今”控件点击后，读取框架选择态并执行网站校验。不要编造截至日替代已经支持的至今。
- 顶部简历解析上传不一定出现在正文附件字段。可结合上传成功响应、暂存请求的 resume 文件引用与 Code 200、源文件哈希及预览验证关联；只有文件名不足以证明保存。
- 附件下载链接在新标签打开可能形成空白目标，并导致 CDP 接入等待所有页而超时。确认只关闭本次产生的空目标，保留真实表单。优先在已登录页面上下文读取观察到的下载链接；独立 request 上下文可能返回 HTML 登录页，不能误报附件不存在。
- 网站强制要求不存在的论文发布日期，或要求本人手写签名时，保存已确认内容并明确记录阻断；不制造论文、日期或签名来通过。
