# 秋招投递 Edge 扩展 V0.1

这是一个本地优先的半自动网申填表原型。它读取 `offer-resume-import.json`，扫描当前招聘网页，只填写高置信度的普通文本字段，并把复杂、敏感或缺少事实的字段留给用户确认。

## 安装

1. 在 Edge 地址栏打开 `edge://extensions`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本文件夹，也就是包含 `manifest.json` 的目录。
5. 打开普通招聘网站，点击工具栏中的“秋招投递”图标。

## 使用

1. 在侧栏导入 `offer-resume-import.json`。
2. 打开招聘网站的简历填写页面。
3. 点击“扫描页面”。绿色描边表示首版可以安全填写；橙色表示需要确认。
4. 检查识别结果后点击“极速填写”。
5. 人工检查页面值、下拉框、日期、附件和敏感问题。
6. 用户自行预览并提交。扩展不会自动提交。

## 第一版边界

- 支持普通文本、邮箱、电话、数字、URL、文本域和可编辑文本区域。
- 暂不自动操作下拉框、日期、单选、多选、地址级联、经历卡片和文件上传。
- 暂不连接任何 AI 服务，也不会上传导入的简历数据。
- 不在 Edge 设置页、新标签页、扩展商店等受保护页面运行。
- 扫描与填写报告保存在本机扩展存储，可从侧栏导出。

## 隐私与控制

- 登录、验证码、OTP、敏感声明、附件和最终提交必须由用户确认。
- 导入数据保存在 `chrome.storage.local`。
- 清除扩展数据时，点击侧栏中的“清除”，或在 Edge 中移除扩展。

## 下一版方向

- 从现有秋招知识库自动同步已核验事实。
- 适配原生及常见框架下拉框、日期控件和多经历卡片。
- 只把未匹配字段发送给可配置的 AI，并在写入前展示建议和依据。
- 将填写报告同步到秋招看板，严格区分草稿、预览和已提交。

## 分享包示例

本目录提供 `offer-resume-import.example.json`，内容全部虚构，只可在本地练习页测试。真实使用前另存私人副本并替换为本人确认资料。此原型使用 Offer 的 name/data 格式，桌面版使用 profile.json，二者不能直接互换。
